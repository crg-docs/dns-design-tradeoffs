## 進め方

一度に複数章の本文を生成せず、要件定義と評価観点・一つの設計事例・出典という単位で刻む（`AGENTS.md` および `outline.md` の執筆単位）。判定者が著者本人であるため、差分が小さいほど判定が正確になる。これが章ごとに進める理由。

次の一手は #4 第2章の一次資料実読 → #22 第1章（見取り図）の本文化 → #6 第2章の本文化。この順にするのは、第1章と第2章がどちらもホスト表から始まり、材料が正面衝突する唯一の箇所だからである。年表を先に書いて境界を確定させないと、第2章が年表を再語りしてしまう。第3章（性能）は出典が検証済みでいつ書いても安全側なので、後回しでよい。
